ЭТАП 4. СИНТЕЗ И РЕАЛИЗАЦИЯ В ПЛИС (Intel Quartus Prime 25.1)

Цель: трансляция RTL ядра top_cpu в конфигурацию MAX 10, отчёт по ресурсам и Fmax.

Инструмент и проект
  Quartus Prime Lite 25.1std.0 (Intel/Altera; не Xilinx Vivado).
  Проект: quartus/top_cpu_quartus/top_cpu_quartus.qpf
  Top-level: top_cpu (только rtl/, без testbench).
  ПЛИС: 10M08DAF484C8G (MAX 10, 8064 LE).
  Такт: quartus/constraints/top_cpu.sdc — create_clock 20 ns (запрошено 50 МГц).
  Быстрый прогон: quartus\run_compile.bat или Processing → Start Compilation.

Соответствие терминам методички и полям Quartus 25.1
  LUT (комбинационная логика)     → Total combinational functions (fit.summary)
  Flip-Flop (регистры)            → Dedicated logic registers (fit.summary)
  Block RAM                       → Total memory bits (fit.summary)
  Общая логика (справочно)        → Total logic elements (LE)
  DSP                             → Embedded Multiplier 9-bit elements
  Fmax                            → sta.rpt → Slow 85C Model Fmax Summary

Результаты использования ресурсов (после Fit, fit.summary)
  Total logic elements ........ 5624 / 8064 (70 %)
  Total combinational functions  3457 / 8064 (43 %)
  Dedicated logic registers ..... 4242 / 8064 (53 %)
  Total memory bits ............. 0 / 387072 (0 %)
  Embedded multipliers .......... 0 / 48 (0 %)
  Total pins .................... 36 / 250 (14 %)
  Fitter Status ................. Successful

Пояснение по Block RAM: ROM и RAM в RTL описаны reg-массивами; синтезатор
разместил их в логических элементах (0 M10K). Для отчёта указать честно; ROM
задаётся quartus/program.mif (образ sum_series).

Анализ времени (Timing Analyzer, sta.summary / sta.rpt)
  Задано ограничение: clk 50 МГц (период 20 ns).
  Setup slack (Slow 1200mV 85C): -21.301 ns — при 50 МГц ограничение НЕ выполнено.
  Hold slack: +0.378 ns — выполнено.
  Fmax Summary (Slow 85C Model): 44.84 МГц (clk).
  Fmax Summary (Slow 0C Model): 46.86 МГц (clk).

Вывод для пояснительной записки: ядро помещается в 70 % LE MAX 10; запрос 50 МГц
в .sdc завышен относительно достигнутого Fmax ~45 МГц. Для гарантированной работы
снизить частоту в .sdc (например 40 МГц, период 25 ns) или оптимизировать критический путь.
