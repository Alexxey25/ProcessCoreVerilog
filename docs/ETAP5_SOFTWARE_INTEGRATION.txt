  ЭТАП 5. ПРОГРАММНО-АППАРАТНАЯ ИНТЕГРАЦИЯ
  Проект: top_cpu (Harvard, Verilog)
1. СТРУКТУРА ФАЙЛОВ
  software/sum_series.asm      — единственная тестовая программа (сумма 1+2+...+10)
  software/cpu.inc             — макросы ISA для FASM
  tools/build_program.sh       — FASM + fasm2hex.sh
  tools/fasm2hex.sh            — bin → hex для instr_mem
  tb/program.hex               — машинный код в ROM (симуляция и Quartus)
  tb/tb_top_cpu.v              — testbench top_cpu, проверка R2=55
  sim/run_stage5.sh            — сборка sum_series и симуляция
  sim/stage5_simulation.log    — лог прогона
  sim/tb_top_cpu.vcd           — осциллограмма для GTKWave
2. КАК СОБРАТЬ ПРОГРАММУ
  Из корня проекта (нужен FASM в PATH):
    fasm software/sum_series.asm
    bash tools/fasm2hex.sh software/sum_series.bin tb/program.hex
  Или одной командой:
    bash tools/build_program.sh software/sum_series.asm tb/program.hex
3. КАК ПРОВЕРИТЬ НА СПРОЕКТИРОВАННОМ ЯДРЕ
    bash sim/run_stage5.sh
  Либо полная верификация этапа 3 (включая top_cpu):
    bash sim/run_verification.sh
4. ТЕСТОВАЯ ПРОГРАММА sum_series.asm
    - N = 10 в R1, сумма в R2, текущее i в R3
    - Цикл: sum += i; i++; counter--
    - Выход по BEQ когда counter == 0
    - Ожидаемый результат: R2 = 55, R1 = 0, R3 = 11, PC = 9 (halt)
5. РЕЗУЛЬТАТЫ
Исходник: software/sum_series.asm
Сборка: FASM + tools/fasm2hex.sh
Машинный код: tb/program.hex
Критерий успеха: Top-level simulation PASSED (sum_series, R2=55).
