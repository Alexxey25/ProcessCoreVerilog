После симуляции Icarus Verilog создаёт файлы VCD в папке sim/:

  sim/tb_pc.vcd
  sim/tb_reg_file.vcd
  sim/tb_data_mem.vcd
  sim/tb_instr_mem.vcd
  sim/tb_control_unit.vcd
  sim/tb_alu.vcd
  sim/tb_top_cpu.vcd          <-- главный для отчёта по процессору

Скриншоты для отчёта делаются ВРУЧНУЮ в программе просмотра waveform.
Это стороннее ПО (не часть Verilog-кода проекта).

--------------------------------------------------------------------------------
Вариант A: GTKWave в WSL (рекомендуется в задании курса)
--------------------------------------------------------------------------------

1. Установка (один раз в Ubuntu/WSL):

   sudo apt update
   sudo apt install -y gtkwave

2. Запуск из корня проекта:

   cd /mnt/d/Users/Desktop/verilogProject
   gtkwave sim/tb_top_cpu.vcd

3. В окне GTKWave:
   - слева раскройте tb_top_cpu -> uut
   - перетащите в область сигналов: clk, rst_n, pc_out, instr_out, state_out
   - для регистров: uut.regfile.dbg_r1, dbg_r3, dbg_r7
     (массив registers[] в VCD Icarus часто не показывается)
   - для памяти: uut.dmem.dbg_ram1

4. Сделайте скриншот (Print Screen / Win+Shift+S) и сохраните в:

   sim/screenshots/tb_top_cpu_waveform.png

   (папку screenshots создайте сами при первом сохранении)

--------------------------------------------------------------------------------
Вариант B: GTKWave / PulseView на Windows
--------------------------------------------------------------------------------

Если установлен GTKWave для Windows, откройте файл:

  D:\Users\Desktop\verilogProject\sim\tb_top_cpu.vcd

Путь к файлу можно скопировать из проводника.

--------------------------------------------------------------------------------
Какие сигналы показать в отчёте (минимум)
--------------------------------------------------------------------------------

  clk, rst_n
  pc_out, instr_out
  state_out
  uut.ctrl.reg_write, uut.ctrl.mem_write, uut.ctrl.pc_load
  uut.regfile.registers[1], [2], [3], [4], [7]
  uut.dmem.ram[1]

На диаграмме должно быть видно:
  - сброс;
  - загрузку R1=5, R2=3;
  - R3=8 после ADD;
  - запись MEM[1]=8;
  - переход PC на адрес 8 (BEQ);
  - цикл JUMP на PC=9.
